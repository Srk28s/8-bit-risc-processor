# 8-bit RISC Processor using Verilog HDL

## Project Overview
This project implements an 8-bit RISC Processor using Verilog HDL.

The processor is being developed step-by-step starting from arithmetic building blocks to a complete processor architecture.

---

## Completed Modules
- Half Adder
- Full Adder

---

## Folder Structure

### verilog/
Contains Verilog HDL source files.

### testbench/
Contains simulation testbenches.

### waveforms/
Contains EPWave simulation outputs.
